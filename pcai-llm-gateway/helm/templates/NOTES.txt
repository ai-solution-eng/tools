════════════════════════════════════════════════════════════════════
1. SECRETS — the pod stays in CreateContainerConfigError until the
   ones it references exist. {{ if or .Values.adminApiKey.create .Values.secretsMasterKey.create (and $embedded .Values.database.embedded.auth.create) }}(Requested ones are generated by this release.){{ end }}

  Admin keys for /admin — ALWAYS required:
  {{- if .Values.adminApiKey.create }}
  # GENERATED by this release (lookup-preserved on upgrade). Fetch a key:
  kubectl -n {{ $ns }} get secret {{ $adminSecret }} \
    -o jsonpath='{.data.{{ .Values.adminApiKey.existingSecretKey }}}' | base64 -d; echo
  {{- else }}
  kubectl -n {{ $ns }} create secret generic {{ $adminSecret }} \
    --from-literal="admin-api-keys=$(openssl rand -hex 32)"
  # Read it back:
  kubectl -n {{ $ns }} get secret {{ $adminSecret }} \
    -o jsonpath='{.data.{{ .Values.adminApiKey.existingSecretKey }}}' | base64 -d; echo
  {{- end }}

  {{- if $embedded }}
  Postgres — EMBEDDED (StatefulSet {{ .Values.database.embedded.serviceName }} in this namespace):
  {{- if .Values.database.embedded.auth.create }}
  # Password GENERATED by this release (seeds the data dir on FIRST init
  # only — never rotate the Secret without ALTER USER).
  {{- else }}
  kubectl -n {{ $ns }} create secret generic {{ .Values.database.embedded.auth.existingSecret }} \
    --from-literal="password=$(openssl rand -hex 24)"
  {{- end }}
  {{- else }}
  Postgres — EXTERNAL (PCAI/site-provided). The gateway applies its schema
  at startup — point it at a database it may CREATE TABLEs in:
  kubectl -n {{ $ns }} create secret generic {{ $dbSecret }} \
    --from-literal=database-url='postgresql://<user>:<password>@<host>:5432/<database>'
  {{- end }}

  {{- if .Values.secretsMasterKey.create }}
  Fernet master key — GENERATED by this release (enables panel credential
  storage; rotating it invalidates stored credentials — re-save from panel).
  {{- else if ne .Values.secretsMasterKey.existingSecret "" }}
  Fernet master key for panel-stored credentials (optional but recommended):
  kubectl -n {{ $ns }} create secret generic {{ $mkSecret }} \
    --from-literal="master-key=$(openssl rand -hex 32)"
  {{- end }}
