## 0. Verdict

**Nothing in this sweep makes a pinned model silently serve as another model** — that invariant survived a third independent audit (zone A re-tested it explicitly and ruled out every vector except the two already-known breaker/budget ones). The most serious new findings are *not* in the model-choice path; they are in the **controls around it**: a masking control that leaks, an auth-expiry check that is missing on one door, a fail-safe that inverts, and a handful of budget/gate arithmetic defects.

Ranked by what they can actually cost you:

| # | What | Where | Why it matters |
|---|---|---|---|
| 1 | Post-call guardrail **masking leaks the unmasked text** | relay (ZC-3) | The one control whose contract is "the mask must not leak" leaks on three channels |
| 2 | Expired **shadow key still authorizes** | core (C2) | Expiry is enforced on one door and not the other |
| 3 | **Off-peak fail-safe inverts** — discount turns ON when demand is unknown | distilling/off-peak (D-3) | Money, and it fails in the *unsafe* direction |
| 4 | **Token-budget gate admits an exhausted budget** | core (C1) | The gate that is supposed to stop spend |
| 5 | **`limit_usd: NaN` accepted** → 500 on every admission for that key + USD gate never refuses | core (F1) | Denial-of-wallet + permanent 500 |
| 6 | **Routing ceiling never availability-checked** → 403 on *every* routed request for an ACL-restricted key | routing (F1) | The routing feature is unusable, not degraded, for those keys |
| 7 | **Dedup suppression never marks** → the same row re-runs a 25-call map-reduce every sweep, forever | distilling (D-2) | Unbounded model spend with zero output |
| 8 | **Title-row filter is inert** (JSONB arrives as `str`) → title-stub memories are distilled | distilling (F1) | Reopens a fixed leak; two families converged on this area from opposite directions |
| 9 | **Ambient proxy env can crash the gateway at startup** | relay/core (L-1) | `trust_env` default + a bracketed-IPv6 `NO_PROXY` entry = `InvalidURL` in `Router.start()` |

## 1. P1 findings

### L-1 (P1) — `httpx2.AsyncClient()` honours ambient proxy env: startup crash + silent upstream rerouting **[L-EXEC]**

```
src/pcai_llm/routing/router.py:132-145      Router.start()  -> httpx2.AsyncClient(...)   # no trust_env=
src/pcai_llm/api/routes_admin.py:2114,2173  per-request clients                        # no trust_env=
src/pcai_llm/api/routes_mcp.py:530
src/pcai_llm/core/enroll_memory.py:205
```

httpx defaults to `trust_env=True`, so `_get_proxy_map` parses `NO_PROXY` entries into `URLPattern`s. A **bracketed IPv6 entry — `[::1]`, a standard way to write it and what this workstation's environment carries** — makes `URLPattern()` raise:

```
httpx2.InvalidURL: Invalid port: ':1]'
  httpx2/_client.py:1510  URLPattern(key)  <- inside AsyncClient.__init__
```

`Router.start()` runs in the app lifespan, so this is **not** a per-request 500: the process fails to start (crash loop).

Reproduced three ways:
- `pytest tests/test_clientside.py` with the ambient env → **1 failed, 32 passed**; the failure traceback lands in `src/pcai_llm/routing/router.py:143`.
- the same file with `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy -u ALL_PROXY -u all_proxy -u NO_PROXY -u no_proxy` → **33 passed**.
- `NO_PROXY='127.0.0.1,localhost,::1,[::1]'` alone reproduces it; the rest of the environment is irrelevant.

Second, independent defect in the same setting: with a *valid* `HTTP_PROXY`, every upstream model call is routed through the corporate proxy — model prompts, API keys and completions traverse a host the gateway does not control. The 2026-10-28 audit recorded this as a latent latency risk; the crash path is new and is the reason this is P1 rather than P2.

**Fix:** `trust_env=False` on all five construction sites (or one shared client factory), and a startup test that builds the app with `NO_PROXY='[::1]'` set.

### ZC-3 (P1) — Post-call guardrail masked replay leaks the unmasked text **[A-EXEC → L-READ]**

```
src/pcai_llm/api/routes_proxy.py:1854-1859
    # masked: suppress content-carrying chunks (and any original [DONE]),
    # replay the rest verbatim, then the consolidated masked content.
    for chunk in chunks:
        if not _sse_delta_texts(chunk) and b"data: [DONE]" not in chunk:
            yield chunk
    yield _sse_masked_final(model, request_id, guarded_text)
```

The "does this chunk carry text?" predicate only looks at `delta.content`:

```
src/pcai_llm/api/routes_proxy.py:1291-1316   _sse_delta_texts()
    content = delta.get("content")
    if isinstance(content, str) and content: out.append(content)
```

so every chunk whose payload rides another channel is classified as "no text" and **replayed verbatim, unmasked**: `delta.reasoning_content` / `delta.reasoning`, the `pcai` thinking event, and tool-call argument deltas. A guardrail that redacts a secret from `content` therefore hands the same secret back on the reasoning channel of the same response.

Confirmed by reading both functions end to end. The auditing model also reproduced it by driving `_guarded_sse` with a stubbed ledger.

**Fix:** classify on *any* text-bearing field (content, reasoning spellings, tool-call arguments, pcai payloads) — i.e. reuse `toolrelay._reasoning_text_of` + the tool-call extractor rather than a second, narrower predicate.

### C2 (P1) — An expired token-shadow key keeps authorizing **[A-EXEC → L-READ]**

`core/identity.py:726-784` — `find_shadow_key` / `_row_to_key_record` never read `expires_at`, while `core/keys.py:load_key_record` refuses the same row. Expiry is therefore enforced on the API-key door and not on the JWT/SSO door. The auditor reproduced it (expired-in-2020 row → `KeyRecord` from one path, `None` from the other). `mcp_admin` is also never selected on that path.

**Fix:** one row→record mapper shared by both doors, with the expiry check inside it.

### D-3 (P1) — Off-peak fail-safe is inverted: discount turns ON when demand is unknown **[L-EXEC]**

```
src/pcai_llm/core/offpeak.py:343-367   first_float()
    if parsed is not None:
        found = _extract(parsed)
        if found is not None: return found
    m = _NUM_RE.search(text)          # <-- fallback scans the WHOLE payload
```

A *successful* Prometheus response with an empty result set still contains numbers (`elapsed_ms`, `took`, `seriesFetched`). `_extract` walks arbitrary values, so the "first number in the payload" becomes the utilization sample. Being near zero, it sits below `offpeak_enter_pct` → hysteresis declares low demand → **the discount engages precisely when there is no signal at all**, which is the opposite of the module's documented fail-safe (unknown → full price).

Reproduced by the lead:

```
first_float({'status':'success','data':{'resultType':'vector','result':[]},'elapsed_ms':3})            -> 3.0
first_float({'status':'success','data':{'resultType':'vector','result':[]},'stats':{'seriesFetched':0}}) -> 0.0
first_float({'status':'success','data':{'resultType':'scalar','result':[]}})                          -> None   (only this shape is safe)
```

**Fix:** treat `data.result == []` as *no sample* (return `None` before any scan), and restrict the fallback regex to the sample subtree rather than the whole payload.

### C1 (P2→P1) — The token-budget gate admits an **exhausted** budget **[A-EXEC → L-READ]**

`core/budgets.py:331-340` compares `spent + est*(1 - billing_fraction) > limit` (with the default 0.9 fraction that is `spent + est/10`), while the USD gate and `model_capacity` use `spent >= limit`. At `spent == limit == 100000` the auditor measured estimates of 0/5/9/10 tokens **admitted** and 1024 refused; the USD family refuses at equality and `model_capacity` reports the same key blocked. The two zero-estimate paths — the relay's per-iteration gate and `/mcp` — therefore admit forever.

**Fix:** use `spent >= limit` for the hard stop (keep the fraction for the *projected* comparison), and add a boundary test at `spent == limit` for all three gates.

### F1 (P1) — `limit_usd: NaN` is accepted and poisons the budget row **[L-EXEC]**

```
src/pcai_llm/core/budgets.py:116-121
    raw_usd = b["limit_usd"]
    if isinstance(raw_usd, bool) or not isinstance(raw_usd, (int, float)) or raw_usd <= 0:
        raise ValueError("limit_usd must be a positive number")
```

`nan <= 0` is **False**, so NaN passes; `float(nan)` is persisted. Two consequences, both confirmed:

```
NaN limit_usd accepted -> [('m','day',nan)]
spent >= nan            -> False        # the USD gate can never refuse this row
int(spent*100/nan)      -> ValueError: cannot convert float NaN to integer   # 500 on every admission
```

Python's `json.loads` accepts bare `NaN`, so an admin payload (or a console bug) can reach this without any exotic encoding. `limit_tokens` is protected by its `isinstance(int)` check; `limit_usd` is not.

**Fix:** reject non-finite explicitly (`math.isfinite`) on both fields, plus a `CHECK` constraint on the column.

### Routing F1 (P1) — The ceiling is never passed to `available()` **[L-EXEC]**

```
src/pcai_llm/core/model_routing.py:344-352
    chosen = cheap_first[pos]
    if available is not None and not available(chosen):
        for p in range(pos + 1, ceil_pos + 1):        # only walks UP
            if available(cheap_first[p]): chosen = cheap_first[p]; break
        else:
            chosen = ceiling                           # <- returned unchecked
```

With no floor configured `floor_pos == ceil_pos`, so the pick **is** the ceiling — and the walk can never leave it. Reproduced with an ACL allowing only Qwen:

```
cheap_first = [Qwen, GLM, Deepseek]; available = (m == Qwen)
score=10        -> Deepseek   reason=prompt_tokens<tier1
score=5000      -> Deepseek   reason=prompt_tokens<tier2
score=10000000  -> Deepseek   reason=prompt_tokens>=tier2
```

The router returns a model the key cannot use; admission then 403s. For a key whose ACL excludes the ladder head, **every** `routing` request fails — the feature does not degrade, it is unusable. It also contradicts the module's own "routing must never make an answer worse" contract.

**Fix:** validate the final choice against `available`; if the ceiling cannot serve, walk *down* the window and, failing that, raise a named refusal instead of returning an unservable name.

### Distilling F1 (P1) — The title-row exclusion filter never fires **[A-EXEC → L-READ]**

```
src/pcai_llm/core/distill_schedule.py:196
    is_title = title_requests.is_title_messages(row["messages"])
```

`is_title_messages` starts with `if not isinstance(messages, list) or not messages: return False`, and the pool registers **no JSONB codec** (`db/__init__.py` `create_pool` has no `init`; `canonical.py:42` documents the convention), so `row["messages"]` is a **`str`**. The predicate is therefore `False` for every row: title rows are never excluded and get distilled into title-stub memories — the 2026-10-20 leak, reopened.

This is the *inverse* of what the sibling auditor reported (starvation from rows that are dropped but never marked); both are real and they are sequenced: **the filter is inert today**, and once it is fixed the unmarked-drop starvation becomes reachable. Note `distiller.build_transcript` already tolerates the double-encoded `str` shape (recovery added 2026-10-11) — this call site is the one that forgot.

**Fix:** decode at the boundary (`json.loads` when `str`), or register the JSONB codec once on the pool.

### Distilling D-2 (P1) — Near-duplicate suppression never marks, so the row re-distills forever **[L-READ]**

```
src/pcai_llm/core/memory_write.py:156-168
    if hit_session != session_id:
        log.info("memory dedup: suppressed near-duplicate write ...")
        return False, ("near-duplicate of an existing memory ...")
src/pcai_llm/api/routes_distill.py:1040-1041
    if ok:
        await distill_schedule.mark_canonical_distilled(...)
```

Suppression is a **permanent** condition reported through the *failure* channel, so no marker is written and the row stays due. Every sweep then re-runs the whole map-reduce (up to ~25 model calls) to reach the same suppression. Measured by the auditor: 4 passes → 4 map-reduces, 0 writes, 0 markers. `settings.distiller_dedup_superseded` is documented as the switch and is read nowhere.

**Fix:** a distinct verdict (`suppressed`) that writes the marker without writing a memory.

## 3. P3 (condensed)

**Routing.** `model_routing.py:337-342` tier-boundary asymmetry (`== t1` jumps to the mid rung; a 1-span window maps the middle tier onto the ceiling). `:488-533` `_policy_cache` has no invalidator — the global kill switch lags up to 60 s *per user*. `:938-940` the never-downgrade floor is measured in an availability-blind window, so it can pin a conversation to a cooling model (opposite policy to `cascade._reorder_head`). `:958-974` the sticky floor is persisted at pick time, before admission promotion, so it can record a model that never served. `cascade.py:100, 494-501` `Resolution.order` is returned unfiltered by the key ACL (every consumer re-filters today — latent). `routes_proxy.py:3960-3975` `/v1/models` advertises `routing__X` outside the key's allowlist. `model_routing.py:257` the turn-adder counts `None`/non-dict message entries.

**Relay.** `toolrelay.py:496-520` (+ two proxy twins) SSE parsing splits only on `\n`: a CR-only (spec-legal) stream parses as one line, `json.loads` fails, and the whole answer vanishes as an empty 200 **[A-EXEC]**. `routes_proxy.py:3405-3421` the client's `tool_choice` is forwarded verbatim on every loop call — `"required"` wedges the loop until the guards kill it. `:2356-2361` a bare tool name gets no granted-tools hint in the unknown-tool error. `:1255-1257` the loop-guard refusal message is off by one ("made 6x" on the 5th hit). `:3580-3581` the relay iteration histogram is a byte-substring match on the emitted stream — 0 for `X-PCAI-Stream-Events: 0` clients, inflatable by model text.

**Distilling.** `distiller.py:95-97` `document_is_complete` is a substring test (a document cut after the last header passes; `## Key decisions` matches a renamed header). `:304-311` `MAX_HISTORY_CHARS` is enforced **after** the append, so one block overshoots the cap and the remainder is dropped silently. `:229-235, 321` `_neutralize` is line-based while the chunker splits on blank lines. `:387-389` an unclosed `[MEMORY INDEX` header counts as body (floor bypass; latent at the default floor 0). `routes_distill.py:103-104` `transcript_body_chars` drops a first message starting with `# Session History`. `:594-595` duplicates the `8_000_000` cap as a literal. `:730-733` the explicit `/v1/distill` takes no sweep lease → a concurrent sweep can double-distill. `distill_schedule.py:534-558` the due query over-fetches 4× with the full `messages` JSONB and never uses it. `canonical.py:466-478` `save()` is unconditional last-write-wins with no CAS on `updated_at` **[HYPOTHESIS]**. `routes_admin.py:3823` an admin `max_tokens=1` passes `ge=0` → every distill raises `DistillTruncatedError` each sweep.

## 4. What's solid (verified, do not "fix")

These were checked specifically because they look suspicious, and they are correct:

- **Pinned models are never silently substituted.** Zone A re-ruled this out end to end; only the two already-known vectors (breaker feed, budget promotion) remain.
- **Sampling parameters and the client body are not rewritten** — the upstream body is the client's body (that *is* finding C-6, but it is not a sampling defect).
- **`split_transcript` loses nothing.** A 300-case property test found zero content loss or duplication across window boundaries; the oversized-block handling is correct.
- **`build_transcript`** tolerates double-encoded rows, char-spread merges, tool calls, tool results and multimodal parts.
- **The distill marker/claim machinery** (lease, `distilled_row_state` snapshot, epoch sentinel, gate backoff) is consistent — the epoch sentinel vs `now()` trap is correctly avoided, and no path writes a marker on failure.
- **`distiller_config` tag round-trip**, `title_requests` detector, `enroll_memory`, `stickiness` read/drop paths, `model_fallbacks`, `effective`/`routes_effective` caps, `routes_dispatch` NaN/inf guards, `routing/router` clock discipline — clean in both families.
- **`_jwks_signing_keys` single-flight** holds (8 concurrent cold-cache callers → 1 fetch).
- **`db/__init__.py`, `metrics.py` cardinality, `traces.py`, `app.py`, `registry.py`, `tool_surface.py`, `federation.py`, `clientside.py`** — no conclusive new defect.
- **The breaker, the settle/ledger path and the guard chain** each carry prior fixes that are present and working in this tree (render-index, silent-`{}` execution, executor exceptions, mid-loop fail-closed gate — four previously-audited defects confirmed *fixed*).

## 5. Test gaps (why these survived)

1. **The suite asserts on source text, not behaviour.** `tests/test_distiller.py:1141` proves `_capture_chat_canonical` exists, not that it is skipped on relay requests (L-2). A string-match test is a green light for an unenforced invariant.
2. **No test crosses the JSONB boundary.** Every distill test injects a `list`; production injects a `str`. That single seam produced F1 (title filter inert) and would have caught the 2026-10-11 double-encoding incident sooner.
3. **The arg-policy 200-string cap is pinned *as intended behaviour*** (`tests/test_arg_policy.py:303`) — the test enshrines a fail-open in a fail-closed stage (C-1).
4. **Boundary values are untested at equality.** `spent == limit` is admitted by one gate and refused by two others (C1); `limit_usd = NaN` has no test at all (F1).
5. **No test sets an environment.** The one failing test in the baseline is *caused* by an ambient `NO_PROXY` entry (L-1); nothing exercises `trust_env`.
6. **A test rebinds `stickiness.set_sticky` without restoring it** (`tests/test_sticky_routing.py:391`) — 10 cross-file failures, and it masks the fact that `cascade._sticky_write_later` has no real coverage.

## 6. Suggested fix order

1. **L-1** (`trust_env=False` + startup test) — cheapest, and it removes an entire class of "works on my machine".
2. **ZC-3** (mask leak) — widen the text predicate to every channel.
3. **C2** (expired shadow key) — one row→record mapper for both doors.
4. **D-3** (off-peak inversion) — treat an empty `data.result` as no sample.
5. **C1 + F1** (budget arithmetic) — equality semantics for all three gates; reject non-finite limits.
6. **Routing F1** (ceiling availability) — validate the final choice, then walk down.
7. **Distilling F1 + D-2** (decode at the boundary; a `suppressed` verdict that marks) — stops the spend loop and the title-stub leak together.
8. Everything in §2, then §3.
