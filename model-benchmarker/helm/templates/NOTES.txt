   Auto-generated on first install (the chart ships no key material).
   Retrieve it:
  kubectl -n {{ $ns }} get secret {{ $name }}-keys \
    -o jsonpath='{.data.BENCH_API_KEYS}' | base64 -d; echo

   Upgrades KEEP the generated value (never rotated under a running

   install) or --set security.existingSecret=<your-secret>. ROTATION (zero
   downtime): the value is a comma-separated list of valid keys — append the
   new one, move clients over, drop the old; the app re-reads it per request.
{{- end }}

2. Benchmarks — enabled ONLY against the configured allowlist
   (bench.endpoints). An empty allowlist disables benchmarking (the estimator
   keeps working). One benchmark per endpoint at a time: a second run against
   a busy endpoint is refused with HTTP 409.

3. The memory estimator page is PUBLIC (deterministic math, no secrets, no
   cluster access). Everything under /benchmark/* and /api/runs* needs the key.
