Push JSON Directly

Paste a single model configuration or a JSON array of them to push to MLIS without saving to the catalog, or add them to the catalog above. When adding to the catalog, set "tier" to "h200", "rtx-pro-6000", or "l40s" to choose the GPU class ({% for t in tiers %}{{ tier_labels[t] }}: {{ tier_info[t].quants|join(', ') }} · {{ tier_info[t].vram_gb }} GB{% if not loop.last %} — {% endif %}{% endfor %}) — a missing or misspelled tier silently defaults to h200. The tier shows up as part of the configuration's label under its model; the lab and model grouping is derived from the model itself, not from tier. tier is not pushed to MLIS (MLIS-side GPU class is resource_gpu_type). Note: entries are deduplicated by name + configuration, so re-adding the same configuration is skipped while a different configuration of the same model is kept. version is assigned by MLIS on push, not authored here.
