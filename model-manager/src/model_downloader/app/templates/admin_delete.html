Manual deletion

The destructive counterpart to the Storage GC report: pick exact model cache directories from the live scan preview and delete them now. Each row is evaluated by the same three-key rule as the GC report — a provenance manifest exists, no AIOLI packaged_models row references it, and no live job pins it. Deletable rows select freely; soft block rows are referenced by AIOLI and need the explicit per-row override before they can be selected; block rows (protected glob, live job pin, or a cross-check that could not run) can never be selected. The server re-intersects every submitted path with a fresh scan and rejects anything it did not just return, and the deletion Job re-validates each path in-pod before removing it.
